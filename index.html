How Focus 4 works

Focus 4 builds differentiated practice from the topic codes in the AQA GCSE Mathematics 8300 Teaching guidance. Each code (N1, A4, R5, G20 …) is a specific piece of content, and every question is tagged with its code so you can target exactly what your class needs.

Choosing topics

  • Search by code (N1) or keyword (ratio, Pythagoras).
  • The topic list is Foundation by default. Switch to Include Higher to add Higher-tier-only codes (shown in amber), which are useful for stretch and for top-set pupils.
  • Select as many codes as you like — the questions are shared out between them.
  • Quick sets select whole strands or common combinations in one click.

Difficulty

  • Choose Easier, Standard or Harder before generating.
  • You can then nudge individual questions with the Easier / Harder buttons on any card.
  • Questions with several parts print each part — (a), (b), (c) — on its own line, with the answer line running from the question across the page. Multiple-choice options are spread evenly across the width.

Tweaking a question

  • Redo — same code and difficulty, brand-new numbers.
  • Edit — click into the question text and type your own wording (school context, pupil names, a different number).
  • Remove — take the question out of the paper. The total drops by one; + Add puts another one back.
  • Lines — set the answer lines for this one question only, or leave it on default to follow the toolbar setting.

Number of questions and answer lines

  • The Questions box in the toolbar sets how many questions a paper has (1–50). + Add and Remove change that total as you go, so the number always matches what is on the page.
  • Answer lines (all) in the toolbar sets the answer lines for every question at once: No lines, 1 line, 2 lines or 3 lines (three is the maximum).
  • To differ from the class default, use the small Lines dropdown on an individual question card and pick none, 1, 2 or 3. Choose default to put it back under the toolbar setting.
  • On a multi-part question the answer line sits beside each part already, so the count only decides whether those inline lines are printed.

Do Now (six quick questions)

  • Switch Output to Do Now. You get six short questions drawn from up to six topics; select fewer and a topic is used again so there are still six.
  • Questions are chosen to work without a calculator: the generator scores every candidate for the arithmetic it needs and keeps the lightest, preferring whole numbers, short answers and anything that can be left in terms of π.
  • The six questions appear in a slip preview with small print and ruled working space. Redo swaps one question for a fresh one, Easier / Harder change its level, and Edit lets you retype it.
  • Print 2 per page puts the same slip twice on one portrait A4 sheet, with a dashed cut here line across the middle — cut it in half and each pupil gets one.
  • Download JPG saves a 16:9 image of the same slip, for putting on the board. It looks like the printed half.

Exporting

  • Export… as PDF opens the print dialog. Choose Save as PDF (or a printer), with A4 paper in portrait layout. The answer lines you chose are printed under each question.
  • If Focus 4 is embedded inside another page (Google Sites, for instance), embedded frames are not allowed to open the print dialog, so Export… as PDF opens the paper in its own print view tab and prints from there. Same result, one extra tab — choose Save as PDF and close it.
  • Tick Print answer key to print the answers on their own page at the end, away from the questions.
  • Download app (HTML) saves Focus 4 itself as one portable file for colleagues — no install, no internet needed.

Questions that need a printed diagram or graph — reading values from a given graph, completing a Venn diagram, loci, and so on — are left out for now, because Focus 4 cannot draw them. Questions that ask the pupil to draw or construct their own diagram from the information given (for example plotting a graph, a pie chart or a tree diagram) are still included; supply graph paper where it helps.

Questions are generated for practice and are modelled on the style of the published teaching guidance. They are not AQA exam questions and are not endorsed by AQA.
